# Projeto Tarefas Kanban

Este projeto é um script Dart que processa uma lista de tarefas simuladas, trata valores nulos e gera um relatório de status, valores e horas.

## Como usar

1. Instale o Dart SDK: https://dart.dev/get-dart
2. Abra este diretório no terminal:
   ```bash
dart pub get
``` 
3. Execute o projeto:
   ```bash
dart run main.dart
```
4. Para verificar a qualidade do código:
   ```bash
dart analyze
```
5. Para executar os testes:
   ```bash
dart test
```
6. Para formatar o código:
   ```bash
dart format .
```

## Estrutura do projeto

- `main.dart`: código principal do projeto.
- `pubspec.yaml`: configurações do pacote Dart.
- `README.md`: instruções de uso.
- `tarefas-kanban.md`: documento de planejamento e tarefas.

## Observações

- O projeto não usa dependências externas.
- Para executar corretamente, o Dart SDK deve estar instalado e no PATH.
